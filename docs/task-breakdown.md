## 2. 현재 반영된 동작
- 메인 채팅은 요청만 입력받음
- 영상 생성은 음악을 끌 수 있음
- 보컬이 아닐 때는 가사 언어 / 가사 입력 숨김
- 브라우저는 `/api/...`만 호출하고 Next.js가 백엔드로 프록시함
- 결과 저장 위치는 `~/Downloads/장사한컷`
- 업로드 원본은 `~/Downloads/uploads`
