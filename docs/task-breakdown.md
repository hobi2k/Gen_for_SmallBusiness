## 2. 현재 반영된 동작
- GPU가 없어도 실제 결과 파일을 생성한다.
- 이미지는 폴백 카드 이미지라도 `png` 파일로 저장된다.
- 음악은 폴백 경로라도 `wav` 파일로 저장된다.
- 영상은 폴백 경로라도 `mp4` 파일로 저장된다.
- 최종 합성본도 `mp4`로 저장된다.
- 사용자가 `3~10초` 사이에서 영상 길이를 고를 수 있게 반영한다.
- 음악은 그 길이에 맞춰 생성한다.
